여행 일정 노트 (함께 쓰는 버전) · 설치 방법
==========================================

처음 한 번만 컴퓨터에서 설정하면, 그다음부터는 모두 폰에서 씁니다.
  A. Firebase 설정 (공유 데이터를 둘 곳, 무료, 약 15분)
  B. GitHub에 올리기 (앱 주소 만들기, 무료, 약 10분)
  C. 폰에 설치하고 가족 초대하기

무엇이 공유되나요?
  - 함께 보기 (서버): 여행 정보, 일정, 완료/보류, 맛집, 예산·지출, 체크리스트, 참가자,
                      '함께 보기'로 고른 기록
  - 내 폰에만: 사진, 영수증 사진, 단체 사진, '나만 보기' 기록
  - 사진은 여행이 끝난 뒤 '내 사진 보내기' → '사진 합치기'로 한 사람에게 모아요.

비용: Firebase 무료 요금제(Spark)로 충분해요. 카드 등록이 필요 없고 요금이 청구되지 않아요.


A. Firebase 설정
----------------
1. console.firebase.google.com 에 Google 계정으로 로그인
2. "프로젝트 만들기" (또는 "Firebase 프로젝트 시작하기")
   - 프로젝트 이름: tripnote (아무 이름이나 괜찮아요)
   - Google 애널리틱스: 사용 안 함 → 프로젝트 만들기
3. 왼쪽 메뉴 "빌드(Build)" → "Authentication" → "시작하기"
   - "로그인 방법" 탭 → "익명(Anonymous)" → 사용 설정 → 저장
4. 왼쪽 메뉴 "빌드" → "Firestore Database" → "데이터베이스 만들기"
   - 위치: nam5 (United States) 같은 가까운 곳
   - "프로덕션 모드에서 시작" → 만들기
   - 만들어지면 위쪽 "규칙(Rules)" 탭을 누르고, 안에 있는 내용을 모두 지운 뒤
     이 폴더의 firestore.rules 파일 내용을 통째로 붙여넣고 "게시(Publish)"
5. 왼쪽 위 톱니바퀴 → "프로젝트 설정" → 아래쪽 "내 앱"에서 웹 아이콘 </> 클릭
   - 앱 닉네임: tripnote → "앱 등록" (Firebase 호스팅은 체크하지 않아도 돼요)
   - 화면에 나오는 firebaseConfig = { apiKey: "...", ... } 값들을 복사
6. 이 폴더의 firebase-config.js 를 메모장(맥은 텍스트 편집기)으로 열어서
   빈 따옴표 "" 안에 위 값을 하나씩 붙여넣고 저장
   예)  apiKey: "AIzaSy....",
        authDomain: "tripnote-1234.firebaseapp.com",
        projectId: "tripnote-1234", ...
   ※ 이 값은 비밀번호가 아니라서 공개돼도 괜찮아요. 데이터는 4번의 규칙이 지켜요.

B. GitHub에 올리기
------------------
1. github.com 에서 무료 계정을 만들고 로그인
2. 오른쪽 위 "+" → "New repository"
   - Repository name: tripnote / Public 선택 / "Create repository"
3. "uploading an existing file" 링크 → 아래 파일과 icons 폴더를 끌어다 놓기 → "Commit changes"
     index.html, app.js, style.css, sw.js, manifest.webmanifest,
     firebase-bundle.js, firebase-config.js(값 넣은 것), icons 폴더
   (README.txt 와 firestore.rules 는 올리지 않아도 돼요)
4. 저장소의 "Settings" → 왼쪽 "Pages" → Branch: main / (root) → Save
5. 1~2분 뒤 주소가 나와요.  예) https://내아이디.github.io/tripnote/
6. (권장) Firebase 콘솔 → Authentication → "설정" 탭 → "승인된 도메인"에
   내아이디.github.io 를 추가

C. 폰에 설치하고 초대하기
------------------------
[나 (여행 만드는 사람)]
1. 폰에서 위 주소를 열고 설치
   - 안드로이드: Chrome으로 열기 → ⋮ → "앱 설치"
   - 아이폰: Safari로 열기 → 공유 버튼 → "홈 화면에 추가"
2. 홈 화면의 "여행노트" 아이콘으로 열기 → "새 여행 만들기"
3. 준비 탭 → "초대 링크 보내기"로 단톡방에 보내기

[함께 가는 사람]
- 안드로이드: 링크를 Chrome으로 열기 → ⋮ → "앱 설치" → 앱에서 참여 → 내 이름 고르기
- 아이폰: 링크를 Safari로 열기 → 공유 → "홈 화면에 추가"
          → 반드시 홈 화면 아이콘으로 다시 열기 → "초대 코드로 참여" → 코드 입력 → 내 이름 고르기
  ※ 아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로라서, 꼭 홈 화면 아이콘에서 참여하세요.

사용 팁
-------
- 인터넷이 없어도 쓸 수 있어요. 입력한 내용은 폰에 저장됐다가 연결되면 자동으로 올라가요.
  (처음 참여할 때만 인터넷이 필요해요.)
- 왼쪽 위 점 색깔: 초록 = 모두와 동기화됨, 주황 = 올리는 중/연결 중, 회색 = 오프라인
- 기록마다 "🔒 나만 보기 / 👥 함께 보기"를 고를 수 있어요.
- 운전 안내: 일정 카드의 "🚗 가기"를 누르면 Google 지도(또는 고른 앱)가 열리면서 바로 안내가 시작돼요.
  완료를 누르면 "다음 장소로 출발" 버튼이 떠요. 이동 일정은 출발지와 경유지도 넣을 수 있어요.
  Android Auto / CarPlay에 연결돼 있으면 차 화면에도 바로 떠요.
- 꾸미기: ⋯ → "🎨 꾸미기". 여행 색과 날짜 이모지는 모두에게 보이고,
  밝기·글씨 크기·카테고리 색·내비 앱은 내 폰에서만 바뀌어요.
- 사진은 폰 카메라로 찍고, 앱에서는 "갤러리에서 추가"로 골라요. 앱에는 가벼운 사본이 들어가고,
  원본도 보내기 전까지 앱에 잠시 보관돼요.
- 여행 끝나고 여행기 만들기:
    1) 각자 ⋯ → "내 사진 보내기" → 파일을 여행기 만들 사람에게 보내기
       ("원본 사진 포함"이 켜져 있으면 파일이 커요. 카톡보다 Google 드라이브가 편해요.
        너무 크면 "보낼 날짜"를 골라 하루씩 나눠 보내세요.)
    2) 받은 사람은 ⋯ → "사진 합치기"로 파일들을 넣기
       → 앱에는 가벼운 사진이 들어가고, "원본 n장 갤러리에 저장" 버튼으로 원본을 갤러리에 저장
         (아이폰은 공유 창에서 "이미지 저장"을 누르세요. 20장씩 나눠서 저장돼요.)
    3) 보내기를 마쳤으면 ⋯ → "앱에 보관 중인 원본 정리"로 폰 공간을 비우세요.
       (갤러리에 있는 원본은 지워지지 않아요.)
    4) ⋯ → "여행기용 내보내기" → 그 파일을 Claude 채팅에 올리고 "여행기 만들어줘"
- Claude와 일정 짜기: ⋯ → "Claude 일정 붙여넣기" → "요청 문구 복사"를 Claude에게 보내면,
  앱에 바로 붙여넣을 수 있는 형식으로 일정을 만들어 줘요.
- 백업: ⋯ → "이 폰 백업 만들기". 사진과 나만 보기 기록은 폰에만 있으니 여행 후 한 번 만들어 두세요.
- 초대 코드를 아는 사람은 누구나 일정을 보고 고칠 수 있어요. 코드는 가족끼리만 공유하세요.
- 역할: 여행을 만든 사람이 👑 주인이에요. 준비 탭 → "역할 관리 · 주인 넘기기"에서
    👑 주인 (여러 명 가능): 여행 삭제, 역할 바꾸기, 사람 빼기
    참가자 (기본): 일정·예산·체크리스트를 함께 고치기
    👀 보기 전용: 일정과 예산은 보기만, 자기 기록·사진·반응만 남기기
  로 바꿀 수 있어요. 주인을 넘기려면 상대를 '주인'으로 바꾼 뒤 내 역할을 '참가자'로 바꾸세요.
  (역할은 그 사람이 앱으로 참여해서 이름을 고른 뒤에 정할 수 있어요.)
- 다른 사람에게 이 앱 주소를 알려주면 그 사람도 자기 여행을 만들 수 있고, 그 여행은 그 사람이 주인이에요.
  다만 데이터는 내 Firebase에 저장돼서, 나는 Firebase 관리 화면에서 그 일정·지출을 볼 수 있어요.
  가족·가까운 친구가 아니라면 같은 파일로 각자 설치하도록 안내하는 게 좋아요.

업데이트하는 방법 (기능이 추가되거나 고쳐졌을 때)
------------------------------------------------
1. Claude에게서 업데이트 파일(압축)을 받아 컴퓨터에서 압축을 풀어요.
   업데이트 파일에는 firebase-config.js 가 들어 있지 않아요. (내 설정 값은 그대로 유지)
2. GitHub의 tripnote 저장소 → "Add file" → "Upload files"
3. 받은 파일들을 끌어다 놓고 "Commit changes" (같은 이름 파일은 자동으로 바뀌어요)
4. 1~2분 기다리기
5. 폰에서 앱을 완전히 닫았다가 다시 열기 (인터넷 연결된 상태로). 한 번에 안 바뀌면 한 번 더.
- 함께 가는 사람들은 아무것도 안 해도 돼요. 앱을 열 때 자동으로 새 버전이 돼요.
- 여행 일정, 예산, 기록, 폰에 저장된 사진은 그대로 남아요.
- 안내에 "firestore.rules 도 바뀌었어요"라고 적혀 있을 때만 Firebase 콘솔 → Firestore → 규칙에
  새 내용을 다시 붙여넣고 게시하세요.
